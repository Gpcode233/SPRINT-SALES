# SPRINT-SALES

A modern, high-converting responsive landing page and ordering portal for **Sprint Laundry & Boutique**.

## 🌟 Features

- **Engaging Visual Design**: Designed around the vibrant Sprint brand color palette (Sunset Coral, Radiant Fuchsia/Pink, and Vibrant Teal) with modern glassmorphic cards and subtle ambient glows.
- **Hero & Category Showcase**: Highlights current clothing sale promotions with fast one-click prefilling for T-Shirts, Hoodies, Vintage Shirts, Trousers, Dresses, Co-ord sets, and custom items.
- **Interactive Order Form**:
  - Customer Information (Name, Email, Phone/WhatsApp).
  - Clothing Item Selection & Quantity Stepper.
  - Size Picker (XS to XXL & Custom).
  - Store Pickup vs Doorstep Delivery selector.
  - Location Address Input for deliveries with an explicit note: *"Delivery fee may differ based on your location."*
- **Social Media Connectors**: Direct redirects to Sprint's official Facebook and Instagram pages.
- **Instant WhatsApp & Receipt Modal**: Generates order reference tickets and preformatted WhatsApp order messages for one-tap order submission.
- **Icons**: Tabler Icons Webfont.
